## The sentences that should steer decisions

- **The wedge:** "Compass helps you decide what fits now and find the right
  time for what matters." The wedge earns the right to the vision (a personal
  timing/navigation layer).
- **The valuable object is not a reading. It is a changed decision.**
  Candidate north-star metric: % of WAU who act on, schedule, or *consciously
  reject* at least one recommendation per week.
- **The magical loop:** "A meaningful long-term direction becomes one
  well-timed action today." (= Star → next move → timed window. This is
  exactly task #5's Star fast path + Best-next-move.)
- **The moat is judgment, not calculation** — knowing what matters, what
  doesn't, what action follows, when to refuse, how to carry uncertainty.
- **Brand:** the calm navigator — "a navigator with an oracle's depth."
  Hierarchy of metaphor families: Navigation is the brand; weather/tide
  describe conditions; rhythm describes lived patterns; astrology is the
  depth and evidence layer. Each family has a job; don't blend.
- **Language ladder:** brand ("time has texture") → product ("see what this
  moment supports") → action ("start now / find another time / wait") →
  proof ("Mercury hour, rising tide, 47 min remaining"). Trouble = using one
  rung where another belongs.
- **"Disciplined compression"**: the next breakthrough is not a new module;
  it is making three moments astonishingly clear — what fits now · connected
  to what I care about · at a meaningful time. (Validates the current beta
  pass: simplify around the three journeys, don't add.)

# Part 2 — The game plan (pasted later the same day)

Full text held by owner. Operative structure:

**Three parallel tracks:** strategy (category/user/brand/business) · product
(one unmistakable loop) · operating system (disciplined building). Central
rule: *no new feature unless it strengthens the core loop, resolves observed
friction, or removes a beta risk.*

**The core loop to prove:** Orient → Choose → Steer → Place → Return.
Three layers: core (Today, Best next move, Stars, Schedule, Begin, On Deck) ·
depth (Calendar, Log, patterns, Bearings, reports) · expert (full astrology,
practitioner tools).

**Nav for beta:** Today · Plan (Schedule + Begin only) · Guiding Stars ·
Calendar. Break down moves inside the Star. (= beta-pass task #4.)

**Founder OS:** four documents — Constitution (rarely changes) · Current
Product Thesis (monthly) · Evidence Log (weekly) · Decision Log (per choice).
Feature intake: idea → hypothesis → evidence → priority → spec → implementation.
Claude workflow: bounded units; product decisions arrive decided; audit-plan-
implement-test; definition of done includes "a fresh user has been observed
using it."

**Eight-week cycle:** W1 freeze+thesis · W2 first-run compression (= this
pass) · W3 Best next move · W4 Star→move→Plan→Today end-to-end · W5 technical
gate · W6 cohort one (12–18: 6 creatives, 4 productivity refugees, 4
practitioners; observe 5 first sessions) · W7 synthesis · W8 cohort two +
one commercial test.

**Activation ladder:** arrived → oriented → added reality → received value →
ACTED (started/scheduled/consciously rejected) → returned. Tour completion is
NOT activation. Core event: *acts on or schedules a recommendation tied to
real work.*

**Three gates, kept separate:** product beta gate · technical beta gate ·
public paid launch gate (the last needs a human engineer's bounded reviews:
security/auth, DB+migrations, infra, riskiest generated code, final audit).

**Deliberately postponed** until the loop is proven: API products,
practitioner workspace, relational timing, more dashboard modules, complex AI
memory, autonomous rescheduling, Studio-as-product.

**Governing idea:** "We are no longer trying to discover everything Compass
could become. We are trying to prove the smallest experience that deserves to
become the larger vision."
