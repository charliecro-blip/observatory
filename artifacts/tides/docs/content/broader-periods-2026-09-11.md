# Month-ahead content: broader periods

September 11–October 10, 2026. All clocks are fixed CST (UTC−6); add one hour for Chicago daylight time. This is an editorial layout draft, not a new timing result contract.

## Selection rules

- Moon-sign periods use each existing activity correspondence’s sign affinities. They describe a theme, not uniformly favorable conditions throughout the period.
- Planetary backdrops use major conjunctions, sextiles, and trines within 3° of exact, matching the ordinary engine’s standing-aspect orb. The precise boundaries below are computed continuously rather than sampled at noon. Only pairs recognized for the relevant activity contribute support; other pairs require a separate interpretive review.
- Lunar aspects can identify shorter openings within or alongside these periods. Quintiles and other minor aspects are omitted from this revision.
- Stars remain attached to previously checked clear/convergent lunar openings, never an entire sign passage.
- Phase can add context where the activity already uses waxing or waning. Retrogrades and stations should qualify relevant copy, rather than become universal prohibitions.
- These computations have not received an independent ephemeris check.
