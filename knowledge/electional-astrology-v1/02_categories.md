# Categories — Venture → House, Planet, Category-Specific Rules

The classical method: identify the house that governs the matter, treat that
house's ruler as the venture's own significator, and read the Moon (and that
ruler) exactly as in `01_universal_rules.md`, plus whatever is specific to the
category below. House numbers use whole-sign reasoning (works across the
house systems Currents already supports — `houses.ts`).

| Category | House | Co-significator planet(s) | Notes |
|---|---|---|---|
| Business / product launch | 10th (public role) + 1st (the thing's own identity) | Sun, Saturn (structure), Mercury (if trade/commerce-heavy) | Prefer the 10th's ruler angular and unafflicted. A product launch reads its 1st house as *the product's* chart, not the founder's. |
| Marriage / long-term partnership | 7th | Venus (harmony), the Moon (the relationship's own weather) | Classically the most scrutinized election in the tradition — Lilly gives it extended treatment. Avoid Venus retrograde. Avoid the 7th ruler in hard aspect to Mars/Saturn. |
| Signing a contract / important agreement | 7th (the other party) + 3rd (the document itself) | Mercury | Mercury retrograde is a **hard** caution here, not just soft — this is the one category where it should block, not just penalize. |
| Travel (short) | 3rd | Mercury | |
| Travel (long) / relocation | 9th (long journeys) or 4th (if it's about the new home) | Jupiter (long travel), Moon (home) | |
| Writing / publishing | 3rd (the writing itself) + 9th (publishing, wider reach) | Mercury, Jupiter | A launch-of-a-book reads like a hybrid: 3rd for the manuscript, 9th for its public life. |
| Creative work / performance launch | 5th | Venus, Sun | Sun well-placed favors visibility; Venus well-placed favors reception/likability. |
| Home purchase / lease signing | 4th | Moon, Saturn (the structure/commitment) | |
| Job start / new role | 6th (daily work) or 10th (if it's a significant career step) | Sun (10th) or Mercury/Mars (6th, depending on the work's nature) | |
| Financial venture / investment | 2nd (own resources) + 8th (others' resources, if raising capital) | Venus (2nd), the 8th's ruler | |
| Health-related beginnings (starting a practice, treatment, procedure) | 6th (routine/practice) or 1st (the body itself) | — | **Inherits the medical KB's safety floor in full** (`05_safety_and_limits.md`). This app does not, and will not, offer electional timing for medical procedures, surgery, or treatment decisions — that's squarely inside the existing hard exclusions. A *habit* (starting a new wellness routine) is fair game under the 6th house as an ordinary electional category; a *medical procedure* is not. |

## A note on "Launch" as the app already uses the word

The app's Guiding Stars / Goals language already uses "launch" informally (see
`PLANET_ACTIVITIES.Jupiter` and `PLANETARY_HOUR_RULES.Sun/Jupiter` in the
existing code — "launch," "publish," "declare" all already appear as
Fire/Sun/Jupiter-flavored activity verbs). The electional feature should be
positioned as the natural extension of that existing vocabulary — "you've been
told this hour favors launching; here's exactly when to actually do it" — not
a new, disconnected concept.
