Current issue:
The app currently appears to intake natal chart data, but the release check says the birth chart is fixed to one set of coordinates/dev birth data. This is not acceptable for sharing with testers. Each tester’s chart must be calculated from their own birth date, birth time, and birth location.

Goal:
Each tester should be able to enter their own birth data and receive a chart calculated specifically for that tester.

Required inputs:
- birth date
- birth time
- birth location name
- latitude
- longitude
- UTC offset / timezone
- house system currently used by the app, if applicable

Use the existing testerId isolation:
- natal_charts must be scoped by testerId
- Body Weather must use the current tester’s natal chart
- Oracle must use the current tester’s natal chart
- No chart route should use global/default/dev data unless no tester chart exists and the UI clearly says no chart is saved

Implementation requirements:

- where natal chart data is saved
- where chart calculations happen
- where dev/default birth data is hardcoded

- planetary positions reflect that birth date/time
- ASC and MC reflect that date/time/location
- house cusps reflect that date/time/location
